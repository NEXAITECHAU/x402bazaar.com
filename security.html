Why x402 for security?

Per-call billing. No API keys. No subscriptions. No accounts. Just a wallet and a request.

  • AI agents can call security checks inline — no human in the loop, no pre-paid credits, no per-key rate limits to manage.
  • Wallets-as-identity — the calling wallet is the caller. Onchain accountability by default.
  • Composable — pipe endpoints together. Phishing check → URL scan → contract risk → wallet check. Each call pays for itself.
  • No vendor lock-in — open protocol, open source, forkable. Run your own instance if you need scale.
  • Free mirrors for testing — every endpoint has a no-payment mirror at /v1/free/<endpoint> rate-limited to 30/min/IP.
